# AI usage

AI coding agents were used to inspect the simulation stack, implement experiment runners, diagnose baseline failures, generate documentation and execute local validation runs.

AI-generated conclusions are not accepted solely from visual output. Claims must be backed by saved simulator metrics, reproducible commands and explicit validity checks. The known large-batch MJWarp issue was discovered because healthy-control results contradicted real-robot experience and single-world simulation; those batch results are now classified as invalid.

No AI-generated lifetime number should be interpreted as physical Unitree G1 lifetime without model calibration and external validation.
